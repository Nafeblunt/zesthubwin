Getting started

Lua 5.4, all our stuff is in zest

hit the </> button next to configs to open the editor, new script on the left, write it, press Run, if it breaks the console under the editor tells you the line

scripts are just .lua files in luas in your config folder so you can use vs code or whatever and press Reload

zest.ui.checkbox("on", "Show speed", true)

zest.events.on("paint", function()
    if not zest.ui.get("on") then return end
    local me = zest.local_player()
    if not me then return end
    local w, h = zest.screen()
    zest.draw.text(w / 2 + 20, h / 2, math.floor(me.speed) .. " u/s", 255, 255, 255, 255)
end)

Game events

every cs2 game event works, just use the name

zest.events.on("player_death", function(e)
    local victim = e:get_player("userid")
    local killer = e:get_player("attacker")
    if killer and killer.is_local then
        zest.log("killed " .. victim.name .. (e.headshot and " (hs)" or ""))
    end
end)
CallReturns
e.nameevent name
e.whateverthe field, number, string, or nil if its not there
e:get(key)same as e.key
e:get_string get_int get_float get_booltyped versions
e:get_player(key){name, is_local} for userid / attacker style fields, or nil

dont keep e around after the callback, its dead by then so copy what you need

ones youll probably use: player_death player_hurt player_changename round_start round_end weapon_fire bullet_impact bomb_planted bomb_defused item_purchase

editor autocompletes names and fields inside quotes

zest.world_to_screen(x, y, z) (or a {x, y, z} table) gives sx, sy or nothing if its behind you

zest.events.on("paint", function()
    for _, p in ipairs(zest.players()) do
        if p.enemy and p.alive then
            local x, y = zest.world_to_screen(p.origin)
            if x then
                local text = p.name .. " " .. p.health
                local w = zest.draw.measure_text(text)
                zest.draw.text(x - w / 2, y, text, 255, 255, 255, 255)
            end
        end
    end
end)

zest.config

get/set any setting with its name from the config file, not case sensitive

FunctionNotes

    zest.log(v.name, v.type)

zest.events.on("createmove", function(cmd)
    local me = zest.local_player()
    if me and not me.on_ground and math.abs(me.velocity.z) > 20 then
        zest.ragebot.hold()
    end
end)

Buttons

For cmd.buttons: zest.IN_ATTACK zest.IN_ATTACK2 zest.IN_JUMP zest.IN_DUCK zest.IN_FORWARD zest.IN_BACK zest.IN_MOVELEFT zest.IN_MOVERIGHT zest.IN_USE zest.IN_RELOAD zest.IN_SPRINT

if cmd.buttons & zest.IN_JUMP ~= 0 then ... end   -- holding jump
cmd.buttons = cmd.buttons | zest.IN_DUCK             -- press duck
cmd.buttons = cmd.buttons & ~zest.IN_ATTACK          -- release attack

Limits

  • 25 ms per callback, 500 ms to load, go over and the script gets killed so infinite loops wont freeze your game
  • errors kill the script too, fix it and hit Run
  • max 256 ui controls per script
  • normal libs work (string, table, math, utf8, os, io) but no os.exit
  • if your script does the same thing as a built-in feature turn the built-in off or theyll fight

Examples

Min damage on crosshair

zest.ui.checkbox("on", "Show min damage", true)

zest.events.on("paint", function()
    if not zest.ui.get("on") then return end
    local me = zest.local_player()
    local md = me and me.weapon and zest.config.get(me.weapon .. "_MinimumDamage")
    if not md then return end
    local w, h = zest.screen()
    zest.draw.text(w / 2 + 20, h / 2 + 10, math.floor(md) .. "md", 255, 255, 255, 255)
end)

Anti-aim

zest.ui.tab("Anti-aim", "shield")
zest.ui.checkbox("on", "Enabled", false)
zest.ui.combo("yaw", "Yaw", {"Backwards", "Jitter", "Spin"}, 1)
zest.ui.slider("range", "Jitter range", 30, 0, 90)

local spin, flip = 0, false

zest.events.on("createmove", function(cmd)
    if not zest.ui.get("on") or cmd.buttons & zest.IN_USE ~= 0 then return end
    cmd.viewangles.x = 89
    local yaw = cmd.viewangles.y + 180
    local mode = zest.ui.get("yaw")
    if mode == 2 then
        flip = not flip
        yaw = yaw + (flip and 1 or -1) * zest.ui.get("range")
    elseif mode == 3 then
        spin = (spin + 15) % 360
        yaw = spin
    end
    cmd.viewangles.y = yaw
end)

Damage log

zest.events.on("player_hurt", function(e)
    local attacker = e:get_player("attacker")
    local victim = e:get_player("userid")
    if attacker and attacker.is_local and victim then
        zest.log(("hit %s for %d (%d left)"):format(victim.name, e.dmg_health, e.health))
    end
end)

Toggle thirdperson on F

local was_down = false

zest.events.on("paint", function()
    local down = zest.key_down(0x46) -- F
    if down and not was_down then
        zest.config.set("Thirdperson", not zest.config.get("Thirdperson"))
    end
    was_down = down
end)
